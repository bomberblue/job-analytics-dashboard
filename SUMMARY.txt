🚀 IMMEDIATE NEXT STEPS (for your 5-person team):

1. PERSON 1 - Environment Setup (15 min)
   $ conda env create -f environment.yml
   $ conda activate job-analytics

2. PERSON 2 - Data Preparation (5 min)
   $ mkdir -p data/raw
   $ cp /path/to/SGJobData.csv data/raw/

3. PERSON 3 - Run Pipeline (30 min)
   $ python src/pipeline/pipeline.py
   ✓ Cleans 50k rows (test mode)
   ✓ Engineers features
   ✓ Creates DuckDB

4. PERSON 4 - Verify Database (10 min)
   $ python -c "from src.database.database_manager import DatabaseManager; \
     db = DatabaseManager(); \
     print(db.query('SELECT COUNT(*) FROM jobs'))"

5. PERSON 5 - Launch Dashboard (5 min)
   $ streamlit run src/dashboard/app.py
   ✓ Opens http://localhost:8501
   ✓ Toggle between Hirer/Seeker views

❓ COMMON QUESTIONS:

Q: Where do I start?
A: Read GETTING_STARTED.md, then Person 1 starts with environment setup.

Q: How do I run the pipeline?
A: python src/pipeline/pipeline.py
   (It will create jobs.duckdb with cleaned data)

Q: How do I launch the dashboard?
A: streamlit run src/dashboard/app.py
   (Opens at http://localhost:8501)

Q: Can I test with fewer rows first?
A: Yes! Change nrows=50000 in pipeline.py to start small.

Q: How do I add a new metric?
A: 1. Add query to database_manager.py
   2. Display in app.py (hirer or seeker view)

Q: What if something breaks?
A: Check error message, read relevant module docstring, ask team.
